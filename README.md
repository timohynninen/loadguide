# Load Guide

A static Three.js cargo loading guide for desktop and mobile browsers.

- [Open the app](https://timohynninen.github.io/loadguide/)
- [Open the load guide directly](https://timohynninen.github.io/loadguide/guide.html)
- [User guide with screenshots](https://timohynninen.github.io/loadguide/user-guide.html)
- [Printable user guide](https://timohynninen.github.io/loadguide/user-guide.pdf)

The example contains 25 indivisible assemblies on 44 EUR pallets, gross weight 5,760 kg. Review the complete trailer, inspect each item, and follow loading stages by item or row. Progress is saved in the same browser on the same device. File upload is deferred to a later version.

The QR code encodes https://timohynninen.github.io/loadguide/guide.html directly.

All runtime assets are local. No account, backend, analytics or build step is required. Serve this directory over HTTP/HTTPS. GitHub Pages publishes the main branch root.
